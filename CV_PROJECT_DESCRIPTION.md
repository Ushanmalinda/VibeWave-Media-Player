# CV Project Description

## VibeWave (Media Player)

Developed a professional cross-platform media player application using Flutter and Dart, inspired by AIMP player.

Implemented automatic file scanning with folder-based navigation for audio and video playback on Android devices.

Integrated advanced playback controls including shuffle mode, multiple repeat modes (Off, Repeat All, Repeat One), and smart previous track navigation.

Designed and built a dual-interface player system with a persistent mini-player and full-screen modal player featuring gradient backgrounds and animated equalizer visualizations.

Implemented comprehensive media format support (MP3, M4A, WAV, FLAC, AAC, OGG, OPUS, WMA for audio; MP4, MKV, AVI, MOV, WMV, FLV, WEBM for video).

Developed automatic device scanning functionality that searches multiple directories (Music, Downloads, DCIM, Movies, Videos, Audio, Podcasts) to organize media files by folder structure.

Integrated gesture-based controls including seek functionality via progress bar dragging and tap-to-play/pause interactions.

Implemented runtime permission handling for Android storage access across different API levels (Android 11-13+).

Tools: Flutter, Dart, just_audio, video_player, file_picker, permission_handler, provider, Material Design 3
